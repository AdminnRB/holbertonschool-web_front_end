# CSS advanced

A responsive marketing website ("Techium") built to practice advanced CSS:
selectors and specificity, box model, CSS variables, grid systems with
floats, pseudo-classes/pseudo-elements, gradients, transforms and
animations.

## Concepts

- CSS fundamentals
- CSS advanced
- CSS specificity and the cascade

## Directory

- `images/` — logos, favicon and the photos used throughout the page
  (hero, services, works, about, latest news, testimonials).
